# 주행 평가 — "사람처럼 운전하는가" (검증 단계, 수정 안 함)

## 검증일시
2026-09-15 10:50 (KST)

## 대상
seoul-drive 자율주행 + 네비게이션. 코드 품질이 아니라 **주행 행동** 을 평가한다.
오너 기준(u_5016): 목적지로 가려면 좌/우회전·유턴을 해야 하고, 차선을 지켜야 하고,
필요할 때 차선을 바꿔야 한다 — 실제 인간 세상과 같이 움직이는가.

## 평가 방법
`games/seoul-drive/eval_driving.py` 신규 작성. 운전에 필요한 항목을 직접 정해 측정한다.
측정을 위해 화면 코드픽셀에 **방향각·경로진행률·자율주행여부** 채널(블록4)을 추가했다
— 밖에서 회전을 판정하려면 차의 방향을 읽을 수 있어야 한다.

| 항목 | 왜 필요한가 |
|---|---|
| 차로유지 | 도로 위에 있는가, 차로중심에서 얼마나 벗어나는가 |
| 조향 건전성 | 항상 끝까지 꺾여 있으면 '조향한다'고 할 수 없다 |
| 회전 | 좌/우회전·유턴을 실제로 하는가(방향각 변화로 판정) |
| 목적지 도달 | 경로 진행률이 올라가는가 |
| 속도 | 목표속도를 따라가는가 |
| 안전 | 사고·급제동 |

## 문제점

### P1 ★교사와 자율주행이 동시에 차를 조종한다 — 근본 원인
- `game.js:1592` 교사 주행 → `game.js:1593` 자율주행, **매 프레임 둘 다 실행**된다.
- 둘 다 `me.steer` / `me.v` 에 쓴다. 교사가 쓴 값을 자율주행이 덮어쓰고, 다음 프레임에
  교사가 또 덮는다. 서로 반대 방향을 요구하면 조향이 ±1 로 튄다.
- 이것이 **조향 포화 97~99%** 의 원인으로 보인다.
- 교사는 `T.set()` 이 `T.auto=true` 로 자동 기동하므로(teacher.js:275) 항상 켜져 있다.

### P2 경로가 즉시 취소된다 → 네비게이션이 사실상 동작 안 함
- 목적지를 넣어도 자율주행이 켜져 있는 시간이 **1.2%** 뿐이고 `wp=0` 으로 돌아간다.
- 경로 진행률이 **역행**(0.034→0.015)했다 = 목적지 쪽으로 가지 않았다.
- P1 과 얽혀 있을 가능성이 높다(교사가 계속 자기 판단으로 몰아 경로를 벗어남).

### P3 목적지가 있어도 회전을 하지 않는다
- 70초간 좌/우회전·유턴 **0회**, 방향각 총변화 39°.
- 사람이 목적지로 가려면 반드시 교차로에서 돌아야 한다. 직진만 하는 건 주행이 아니다.

### P4 목표속도를 절반도 못 따라간다
- 설정 50km/h, 실측 중앙값 **20.5km/h (41%)**.
- P1 의 결과일 수 있다(조향이 포화 → 커브 감속 로직이 상시 발동).

### P5 POI·횡단보도 소실 (이전 검증에서 발견, 그대로 남음)
- POI 60→0, 횡단보도 45→0. `pack_map.py` 가 빈 배열로 내보낸다.
- 보행자 횡단 동작 불가, 검색에서 '명소' 분류 소실.

### P6 차선변경을 '필요해서' 하지 않는다
- 현재 차선변경은 데모 타이머로만 발동한다(12초마다 0↔1).
- 사람은 '앞차가 느려서' '좌회전 차로로 가려고' 바꾼다. 그 판단이 없다.

## 보강할 점 (우선순위순)

1. **P1 제어권 분리** — 교사와 자율주행이 동시에 몰지 않게 한다.
   경로가 있으면 자율주행만, 없으면 교사만. 한 프레임에 한 컨트롤러.
   (조향 포화·속도 미달·경로 이탈이 모두 여기서 파생됐을 가능성)
2. **P2 경로 유지** — 목적지 설정 후 자율주행이 꺼지지 않게. 꺼지는 지점을 로그로 특정.
3. **P3 회전 검증** — 교차로에서 실제로 도는지. 1·2 수정 후 재측정.
4. **P4 목표속도** — 1 수정 후 재측정. 여전히 낮으면 별도 원인.
5. **P5 POI·횡단보도 복원** — pbf_to_chunks.py 에서 추출 → pack_map.py 로 전달.
6. **P6 상황 기반 차선변경** — 앞차 속도·회전 예정 차로를 보고 스스로 판단.
