# Keynote APP-KB (kongtrol 순수비전 조작 참조)

> kongtrol이 순수비전(눈=a11y/UI-TARS·손=물리입력)으로 macOS Keynote 조작 시 참조하는 압축 지식베이스. orch+워커 전용. 단축키·메뉴경로·비전 폐루프 팁 위주.

## 0. 화면 레이아웃 (실측)

| 영역 | 위치 | 내용 |
|------|------|------|
| **상단 툴바** | 창 상단 | 보기 · 확대/축소 · **슬라이드 추가** · 재생 · **표** · **차트** · **텍스트** · **도형** · **미디어** · 주석 · 공유 |
| **우측 상단 탭** | 툴바 우측 | **포맷** · 애니메이션 · 문서 |
| **우측 패널** | 창 우측 | 선택 객체에 따라 변함. 텍스트 선택 시 `스타일 / 텍스트 / 정렬` 탭 |
| **슬라이드 네비** | 창 좌측 | 슬라이드 썸네일 목록(클릭=이동, 우클릭=복제/삭제 메뉴) |
| **캔버스** | 중앙 | 현재 슬라이드 편집 영역 |

- 다크테마 = 배경 검정 / 라이트테마 = 배경 흰색. 표지 슬라이드 = 제목/부제/저자 플레이스홀더.

## 1. 새 프레젠테이션·슬라이드

| 작업 | 방법 |
|------|------|
| 새 프레젠테이션 | 파일 > 신규(⌘N) → **테마 선택** 창(모든 테마/기본/다이내믹...) → 테마 클릭 → "선택"/더블클릭 |
| 새 슬라이드 추가 | 툴바 **"슬라이드 추가"** 클릭 → **레이아웃 팝업** → 레이아웃 클릭 / 또는 ⌘⇧N (추정) |
| 슬라이드 복제 | 좌측 썸네일 우클릭 > 복제 / 또는 ⌘D (추정) |
| 슬라이드 삭제 | 좌측 썸네일 선택 > delete |

**레이아웃 팝업 항목**: 제목 · 제목 및 사진 · 제목 및 구분점(=제목+불릿) · 구분점 · 섹션 · 사진 · 빈 페이지 등.

> 비전 팁: "슬라이드 추가" 클릭 → 팝업 캡처 → 원하는 레이아웃 썸네일 좌표 클릭 → 새 슬라이드가 썸네일 목록에 추가됨(재캡처 확인).

## 2. 텍스트

| 작업 | 방법 |
|------|------|
| 플레이스홀더 편집 | 텍스트박스 **더블클릭** → 편집모드(커서) → 타이핑 |
| 텍스트상자 삽입 | 툴바 **"텍스트"** 클릭 → 캔버스에 텍스트박스 생성 → 더블클릭 편집 |
| 편집 종료 | esc 또는 캔버스 빈 곳 클릭 |
| 전체 선택 | 편집모드에서 ⌘A |

> 비전 팁: 제목/부제/본문은 각각 별도 박스. 박스마다 더블클릭으로 진입해야 그 박스에 입력됨(잘못하면 다른 박스에 붙음 → 재캡처 확인). 오입력 시 ⌘A 후 재입력.

## 7-1. ★★정밀 배치 = [정렬 인스펙터 위치/크기 숫자입력] (핵심 — 드래그 금지)

> ★드래그 배치 = 부정확·겹침(실패원인 2026-08-13). **반드시 [포맷>정렬 탭]의 위치 X/Y·크기 너비/높이 pt 숫자입력**으로 정밀 배치. 슬라이드 = 1024×768pt(위치도 pt).

**절차 (객체 1개 배치):**
1. 캔버스에서 객체 **클릭 선택**(핸들 표시).
2. 우측 상단 **[포맷]** 탭 클릭 → 하위 **[정렬]** 탭 클릭(스타일/텍스트/정렬 중 정렬).
3. **크기** 섹션: **너비** 필드 클릭→⌘A→값 타이핑→tab, **높이** 필드 클릭→⌘A→값→enter.
4. **위치** 섹션: **X** 필드 클릭→⌘A→값→tab, **Y** 필드 클릭→⌘A→값→enter.
5. 재캡처로 객체가 지정 X/Y/W/H로 이동·리사이즈됐는지 확인.

**정렬 인스펙터 필드 좌표 (실측 2026-08-13, 물리px·1512폭 디스플레이·scale2.0. 창위치 바뀌면 재캡처):**
- 크기 **너비** 필드 ≈ (3697, 845) · **높이** 필드 ≈ (3889, 845)
- 위치 **X** 필드 ≈ (3697, 1007) · **Y** 필드 ≈ (3889, 1007)
- ※필드는 a11y 라벨로 안 잡힘 → 스샷/VL로 필드 위치 확인 후 클릭. "정렬" 탭 = 스샷 우측(≈3900px, 526).

> ★비전팁: 필드 클릭 후 반드시 ⌘A(기존값 전체선택)→새값 타이핑→tab/enter. 안 하면 기존값에 덧붙음. tab = 다음필드 이동(X→Y 연속입력 가능).

## 11. 비전 폐루프 공통 팁 (a_18/a_21)

1. **매 조작 후 재캡처 확인** — 팝업 떴나·객체 생겼나·텍스트 들어갔나. "완성" 주장 전 스샷 실측.
2. **박스 컨텍스트 주의** — 더블클릭한 박스에만 입력됨. 잘못 들어가면 esc→해당 박스 재더블클릭.
3. **팝업/다이얼로그** = 비전으로 인식→적절 버튼(계속/생성/열기/허용안함) 클릭.
4. **a11y 우선 → 폴백 UI-TARS** — 텍스트박스·툴바버튼·메뉴는 a11y(AXUIElement)로 빠른 좌표. 캔버스 내부 도형/이미지 등 커스텀 요소는 UI-TARS 비전 grounding.
5. **저장 다이얼로그** = 첫 저장 시 나타남. 이름 타이핑 후 "저장" 버튼 클릭.
6. **좌표계** — 스샷(물리px)·클릭(논리pt=물리÷scale, Retina=2.0). kongtrol input click은 물리좌표 받아 내부 변환.

> 불확실(추정) 표시: ⌘⇧N·⌘D·⌘=·⌘- 및 삽입 메뉴 세부 = macOS Keynote 버전별 상이 가능 → 실사용 시 메뉴바(삽입/포맷)에서 실제 확인 후 갱신.

## 12. ★조작 레시피 (a_36 PHASE A — 실측검증, 스샷 자기분석 없이 실행용)

> ★워커는 스샷을 자기 LLM으로 분석하지 말 것(u_107). 아래 레시피의 [좌표·시퀀스·키]를 결정적으로 실행. 스샷은 orch 검증용 저장만. VL은 색추출 등 불가피 시각판단 1회만.
> ★★좌표계 확정 (2026-08-13 orch 2회 실증): a11y see의 cx,cy = 논리좌표. → [click cx cy --scale 1.0] 그대로 = 정확 클릭. ('새로운문서'779,666→테마화면 · '생성'1522,1030→편집화면 실증). ★눈대중 스샷픽셀·잘못된 ×2 = 전부 폐기. click 코드=X/scale(main.rs:195)이라 논리값+scale1.0이 정답. cf memory [[keynote-two-coordinate-systems]].
> (구주석: `--scale 2.0`+원본px 방식은 혼동유발했음 → scale1.0+a11y논리로 통일)
> ★kongtrol 한계: ~~delete/backspace 키 없음~~(a_40 해결: `input key backspace`(=⌫ 객체삭제)·`input key delete`(forward)·별칭 bs/del/fwd 추가·빌드검증완료)·app 활성화 없음·chord 단일modifier만. → app활성화는 빈페이지 레이아웃·fresh doc·툴바버튼으로 우회.
> ★객체삭제(a_40): 요소 선택 후 `input key backspace`. macOS Keynote 도형·이미지 삭제 표준.
