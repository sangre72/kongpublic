## 3. 이미 고쳐서 효과 본 것 (되돌리지 말 것)

- 교사가 경로 조향을 덮어쓰던 것 차단 → 좌회전 폭주 해결
- UI 클릭이 캔버스로 새어 planTo 재호출(plan=8) → 더블클릭만 허용, plan=1
- 도로 밖 이동을 물리적으로 무효화(하드 구속)
- 사고 시 경로 유지(예전엔 hardReset 이 경로를 지움)
- 출발점을 진행방향 맞는 도로에서 선택(고속도로 68%→100%)
- gAstar 에 일방통행/제자리유턴 금지(역주행 250→0건)

## 4. 현재 구조

- `planTo()` : 전역 그래프 A* → 노드열 → 차로 오프셋 적용 → `auto.wp[]`
- `driveAuto(dt)` : `auto.wp[auto.i]` 를 목표로 조향(df) + 횡오차(xt) 보정
  - 조향식: `df = seg_heading + atan2(-xt*1.6, max(3, v))` (Stanley 유사)
  - `me.steer = clamp(df*2.4, ±0.9)`
- 차량모델: 자전거모델, wheelbase=차길이*0.6, maxSteer=0.62rad
- 웨이포인트 간격: 중앙값 19m, p95 78m

## 6. 참고 (워커 조사 결과 ar_5034 요약)
