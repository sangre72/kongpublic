## 0. 한 줄 목표
**화면 픽셀만 보고 도로교통법을 지키며 목적지에 도착하는 모델(오드)** 을 2D(서울드라이브) → 3D 게임 → 실주행 영상 순서로 키운다. 성공 기준 = 모델이 실제로 도착, 사고 0(오너 규칙).

## 1. 로드맵 (u_5438, u_5441)
| 단계 | 환경 | 배우는 것 | 정답(라벨) 출처 | 상태 |
|---|---|---|---|---|
| 1 | 오드(2D, 서울 실도로 OSM) | **행동**: 조향·가감속·차로유지·추종·보행자·신호·회전 | 게임 내부 상태(교사) — 특권 정보는 라벨에만 | 수집 중(2026-09-19 밤) |
| 2 | 3D 게임(포르자 호라이즌·ETS2/ATS) | **시각**: 조명·날씨·야간·가림 + 행동 재검증 | 게임 텔레메트리(UDP/SDK)로 라벨, 입력은 화면만 | 미착수 |
| 3 | 유튜브 실주행 영상 | 실세계 시각 분포 | 정답 없음 → 광류(ego-motion) 의사 라벨 또는 표현 학습 후 1·2단계 정답으로 미세조정 | 미착수 |
- 세 단계 공통: **입력 = 픽셀**, 공통 전처리(`net.preprocess` 256×256), 후처리 증강(§6). 텔레메트리는 입력이 아니라 라벨 생성용(Learning by Cheating, u_5439).
- 난이도 두 축(u_5440): **행동 난이도 = 오드**(직진 < 차선변경 < 끼어들기 < 다중 회피), **시각 난이도 = 3D 이후**(맑음 < 흐림/그림자 < 야간 < 우천/역광). 2D 게임 렌더는 건드리지 않는다.

## 2. 아키텍처 — 계층형 제어 + 중추 관제망 (u_5436, u_5437, u_5443, u_5444)
```
프레임 ─▶ 관제망 tier net (화면→등급 T0~T3 + 확신도, 64~224px, ~0.1ms)
             │ 제어기 선택
   ┌─────────┼──────────────┐
 규칙 페일세이프   단계별 주행 모델    보수 모드(감속·차선유지)
 (Layer1, 항상)   (Layer2, DriveNet 0.26ms)
             │
 Layer3 라우터(경로·회전차로 준비·유턴구역) = 규칙(planTo/gAstar)
```
- **Layer 1 반사(최우선, 규칙)**: 앞차·보행자·적신호 제동. 관제망 *아래* 하드와이어 — 관제망이 틀려도 끌 수 없다. 현재 `teacher.js compute()` 제동부 + `driveAuto` gap/ped 상한. → 분리·페일세이프화 필요.
- **Layer 2 전술(모델)**: 차선유지·추종·차선변경·회전. `model-drives-not-logic` 원칙은 여기 적용. 단계별 모델(§5).
- **Layer 3 전략(규칙)**: 경로·회전차로 준비(Lprep/Rtl/Stl/Lexit)·유턴 구역. 운영 중.
- **등급 판정**: 오드 = 프레임 태그(M) 규칙 판정(µs). 3D·실영상 = tier net. 오판 방향은 항상 상위 등급(어려운 걸 쉬운 걸로 오판 = 위험). 확신도 < 0.6 → 한 등급 위.
- **지연 예산**(u_5437): 트리거(태그/관제망) ≤0.1ms, 주행 모델 0.26ms(MPS 실측), 모델 명령 타임아웃 150ms → 보수 기본(game.js `_age>150`). 실측 병목은 화면 캡처(1.1~1.6s/프레임, `screencapture` CLI; Quartz 경로는 30s/프레임 재현) → **페이지가 프레임을 밀어주는 `/frame` 방식으로 교체(2026-09-20 첫 과제)**.
- **캐스케이드**: 소형 DriveNet 상시 → T2(보행자·신호) 전용 큰 모델은 데이터 확보 뒤. 투기적 예열은 큰 모델 도입 때.

## 3. 데이터 규격 (u_5426, u_5427, u_5442) — 확장 전제
`data/dagger_r<round>/` 마다:
| 파일 | 형상 | 내용 |
|---|---|---|
| `X.npy` | (N,3,256,256) uint8 | 모델 입력 프레임(픽셀만) |
| `Y.npy` | (N,6) float32 | [조향, 스로틀, 제동, 속도 m/s, 좌 차로여유 m, 우 차로여유 m] — 교사 정답, 도메인 중립 단위 |
| `W.npy` | (N,) float32 | 프레임 가중치. 회피 가능한 사고 직전 3초 = 0, 불가항력(정지거리 안 무단횡단) = 1 유지 |
| `M.npy` | (N,8) → (N,11) | 상황 태그 [gap, ped, sig, turn(0S/1L/2R/3U), aD, v, laneF, nl] + (2026-09-20 부터 `M_EXT=1`) [env(0오드/1포르자/2ETS2), ep, fi(프레임 순번)] — 시간 문맥 모델용 |
| `episodes.json` | | 에피소드 통계(frames, crashes, w0_frames, prog…) |
- 수집기: `dagger.py --model none`(교사 주행, 2026-09-19 밤) / `--model <pt>`(DAgger: 모델 주행 + 교사 라벨).
- `bc_final.pt` 는 옛 DriveNet 구조 → 사용 불가(덮어쓰지도 않음). 순서: 교사 수집 → 1단계 학습 → 새 모델로 DAgger.
- 라운드 = 스윕 구간(`pairs30.json`) 하나, 3에피소드×600초, 라운드마다 텔레그램 통계. 진행 없는 구간(60초 시험에서 prog<0.5%)은 건너뜀 + `collect_watchdog.sh`(90초 뒤 doneM<30 이면 라운드 중단). 기어가기·정차 데이터 금지(규칙 §2).
- 캡처 1.3fps → 라운드당 ≈2,000프레임. 프레임 푸시(§2)로 10fps↑ 확보 후 재수집.

## 5. 학습 커리큘럼 (u_5427) — `train_stage.py`
| 단계 | 선별 조건(M) | 통과 기준(실주행) | 비고 |
|---|---|---|---|
| straight | turn=0, gap>60, ped>40, sig>60 | 차로유지(차선물기 <5%), 속도 유지, 사고 0 | 얕은 망으로 시작 |
| follow | gap<40 | 추돌 0, 간격 유지 | |
| ped | ped<30 | 보행자 정지율 100%(불가항력 제외) | |
| signal | sig<60 | 신호 위반 0 | |
| turn | turn∈{L,R}, aD<80 | 회전차로 준수 ≥99%, 1차로→1차로 | |
| uturn | turn=U, aD<80 | 유턴구역 준수 | |
- 각 단계는 이전 체크포인트(`--init`)에서 이어서, 이전 단계 표본 20% 혼합(`--replay`, 망각 방지). 손실 = W 가중 MSE + 좌우 대칭항. 정지 프레임 증폭 금지(함정: '서 있기'를 배움).
- 이후 DAgger(`dagger.py --model ode_sN.pt`)로 모델 방문 상태의 정답을 보강.

## 6. 도메인 증강 (u_5439, u_5440) — `train_stage.augment()`, 학습 배치에만
밝기 ±0.2·대비 0.7~1.3·가우시안 노이즈 0.03·25% 흑백·채널별 색 지터 ±0.05·30% 흐림(½ 다운→업샘플)·30% 가림 사각형(8~25%). 추론·캡처 경로엔 절대 적용하지 않는다.

## 7. 관제망(tier net) (u_5443, u_5444, u_5445) — `train_tier.py`
- 라벨 = 태그에서 자동 파생: T0 직진·자극 없음 / T1 gap<60 또는 회전 200m 안 / T2 ped<40, sig<60, 골목(nl≤1) / T3 정지거리 안(ped<max(8,정지거리), gap<max(6,정지거리/2)).
- 망: 초소형 CNN, 입력 해상도 인자(`--res`): 2D 64~128, 3D/실영상 128~224. 클래스 가중(희소 등급), 모델 선택 기준 = **T2·T3 재현율**, 확신도<0.6 → 상위 등급.
- 검증: 태그 정답 대비 정확도·어려운 등급 재현율; 사고 3초 전 등급 분포(사고 직전이 T0 였다면 판정기 결함). 아침에 64/128 비교.
- 배선(2026-09-20): 페이지 `/ctl` 에 tier·confidence → 제어기 선택, `/tel tier` 노출, 등급별 사고·법규 집계.

## 8. 검증 체계
- 회귀 10구간(`regression_cases.json`, `run_regression.sh`): 사고 구간을 출발/도착으로 고정. 기대값 = 순간이동 0·갇힘 0·회피가능 사고 0·최소 주행거리. 불가항력은 표시만.
- 30구간 스윕(`sweep_test.py`, `pairs30.json`): 주행거리·사고·회전차로·차선·역주행·보행자 대응. 2026-09-19 결과: 75.6km, 사고0 구간 18/30 → 근본원인 9건 수정.
- 법규 모니터(`law_monitor.py`), 사고 위치 폴러(`crash_watch`). 화면 확인(스크린샷·영상)은 필수 — 숫자만 믿지 않는다.
- 지도 검증: 두 구간이 같은 좌표에서 사고 = 지도. `data6.js` 오프라인 검사(l/o/ld/ls/pc) → 추출기 규칙(형제 차로 상속·간격 상한·청크 분할·oneway 연속성·왕복 짝수 기본값).

## 9. 미해결·다음 할 일 (2026-09-20)
1. 페이지 프레임 푸시(`canvas.toDataURL`→`/frame`)로 캡처 10fps↑ → 재수집.
2. Layer1 페일세이프 분리 + 규칙 등급 판정기 + tier net 배선(§7).
3. 골목 헤어핀(대흥로20안길, 회귀 9): 누적 ≥148° 런을 좁은 도로 K턴 지점으로 / 라우터 회피.
4. 신촌역 m≈530 추돌(좌회전 13~15m 앞, 오른쪽 밀림) 재현.
5. 비대칭 왕복도로(lf≠lb, 96+173 way): 실제 중앙선 `c=(lb−lf)·LW/2`, 차로 k 중심 `c±(k+0.5)·LW`; laneOffset·중앙선 그리기·wrongSide 를 함께.
6. `M_EXT=1`(env/ep/fi) 로 수집 재개.
7. 만리재로16안길→서울공항 m≈3300 도로폭 9.75→16.25 전환 지점(회귀 10): 수집 r103 3에피소드 모두 차로이탈→순간이동→추돌. 폭 변화 구간 경로 오프셋/차로 매핑 점검(offTab).
