# Target identification before execution (MUST — u_4853/u_4854, 2026-09-13)

> **정확히 모르는 대상을 찾거나 다루는 작업은 시작하면 안 된다.**
> "대충 이런 거겠지"로 출발하면 실패해도 원인을 알 수 없고, 성공해도 그건 운이다.

## Trigger
탐색·식별·판정이 들어가는 모든 작업: 이미지에서 대상 찾기(월리·표지판·특정 인물/사물),
UI에서 특정 요소 식별, 상품 선별, 문서에서 특정 항목 찾기 등.

## Rule
1. **착수 전에 대상의 정식 정의를 확보한다.** 내 기억·추정으로 시작하지 않는다.
   - 공개 지식 대상(캐릭터·표지판·규격·브랜드) → **WebSearch로 원전 확인**(위키·공식문서).
   - ★특히 **이미지 검색으로 실제 큰 사진을 참고**한다(u_4853) — 텍스트 설명만으로는
     시각적 판별 기준이 안 선다.
   - 내부 대상(레시피·잡·파일) → 해당 recipe/registry 원문을 읽는다.
2. **식별 기준을 필수조건 / 가변조건으로 나눠 명시한다.**
   - 필수: 없으면 탈락(예: 월리의 빨강흰 줄무늬·방울모자·둥근 안경)
   - 가변: 있으면 보강, 없어도 탈락 아님(예: 월리의 가방·카메라·지팡이)
   - ★이 구분을 안 하면 가변조건을 필수로 착각해 진짜를 탈락시키거나, 필수조건을
     빠뜨려 가짜를 통과시킨다.
3. **디코이(혼동 대상)를 먼저 조사한다.** 대부분의 탐색 과제는 유사물이 설계돼 있다.
   각 디코이를 걸러내는 **결정적 식별축**을 1개씩 확보한다.
   (예: 오들로=줄무늬 색, 웬다=안경 유무, 마법사=수염 유무)
4. 확보한 기준은 **레시피로 남긴다**(kaymaps/_common/RECIPE_<target>_identification.txt).
   다음 세션이 같은 조사를 반복하지 않게.

## Anti-pattern (실제 사고)
- 2026-09-13 L11: "빨강흰 줄무늬 + 방울모자"만으로 월리를 판정 → 계속 실패.
  원전을 안 찾아봐서 **둥근 안경(웬다 배제축)·줄무늬 양말**을 몰랐고,
  **오들로(노랑검정 줄무늬+콧수염)**라는 공식 디코이의 존재 자체를 몰랐다.
  반대로 **가방·카메라를 필수로 오해**해 진짜 월리를 탈락시킬 뻔했다.
- L9: 팔각형 모양만 보고 정지 표지판이라 단정(색·글자 미확인) → 오답 3칸.
- 오너 지적: "모르면 인터넷 검색을 하라 그랬는데 너 안 하더라"(u_4853),
  "정확히 모르면서 뭔가를 진행할 순 없어. 한 번에 찾은 건 운이 좋았던 것"(u_4854).
