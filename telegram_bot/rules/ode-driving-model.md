# 오드(ODE) — 자율주행 모델 이름 (u_5143, 2026-09-15)

> 오너: "오드 라고 이름짓자. 앞으로 자율주행 모댈 이름은 오드로 명명하겠어."

## 명명
- 자율주행 모델 = **오드 / ODE**
- 체크포인트·로그·문서·텔레그램 보고에서 이 이름을 쓴다.
  현재 가중치 `bc_final.pt` 가 오드의 현재 세대다.
- 세대 표기: `오드 v1`(BC), `오드 v2`(DAgger 회피/추월 학습) 처럼 이어간다.

## 왜 이름을 붙이나
'모델'이라고만 부르면 수식 주행(driveAuto)·교사(teacher.js)와 말이 섞인다.
실제로 이 세션에서 "모델이 몰고 있다"고 보고했다가 화면은 DRV=GEOM 이었던 일이
반복됐다. 이름이 있으면 **누가 몰았는지**를 틀리게 말하기 어려워진다.
