# 닫힌 루프 수치는 반복 없이 받아들이지 않는다 (MUST — 오너 u_5747, 2026-09-29)

> 워커 보고: "같은 구간·같은 설정인데 sc 17.40 vs 6.48." 오너: "가장 가치 있는 보고. 수용 기준을 바꾼다."

## 실측 (노이즈 바닥)
동일 구간·동일 설정(`stema=0`)·1시간 간격 재실행:
```
alley 형촌6길>역삼로78길     sc 17.40  vs  6.48   (2.7배)
two   삼학사로19길>올림픽로37길 sc 13.76  vs 31.04   (2.3배)
```
⇒ 구간별 `sc` 의 실행 간 산포가 **±2.5배**. 우리가 비교하던 효과 크기보다 **노이즈가 크다**.

## 규칙
1. **주행(닫힌 루프) 수치로 합격·불합격을 말하려면 조건당 반복 ≥3 회**, 평균과 표준편차를 같이 적는다.
   단일 실행은 **스크리닝 신호**일 뿐이며 "개선/악화" 판정 근거로 쓰지 않는다.
2. 비교는 **같은 세션·같은 시간대**의 대조군과 한다. 1시간 전 대조군과 비교하지 않는다.
3. 효과가 **해당 지표의 sd 안**이면 "차이 없음"으로 보고한다. 방향만 보고 결론내지 않는다.
4. **오프라인·결정론적 결과는 이 규칙의 대상이 아니다**(같은 프레임셋·같은 디코딩이면 재실행해도 같은 값):
   리플레이 순위, GRU 관문(0.79/0.84), 원호 관문(0.96), 수집·커버리지 집계. 이들은 단일 실행으로 유효하다.
5. 구간별 지표가 불안정하면 **합격 지표를 범위 내 eval20 중앙값(20구간)으로 올린다** — 구간 하나의 sc 는
   스크리닝용. 지속시간 연장(300→600초)이 sd 를 줄이는지는 **채택 전에 측정**한다.

답이 "1회"면 그것은 결과가 아니라 표본 하나다.

### 규칙
1. **주 지표 = `amp`(횡오프셋 진폭 p95).** 분산이 가장 낮을 뿐 아니라 오너의 갈지자 정의(u_5579: 진폭·변화율,
   중앙편차 아님) 와 같은 것을 재는 지표다. 합격·불합격은 amp 로 말한다.
2. **`sc` 는 스크리닝 전용.** 300초 n=3 에서 75% 미만 효과는 검출 불가 — "sc 가 좋아졌다"는 판정 근거가 아니다.
3. **`corner_xt95` 는 n 개의 중앙값으로 보고**하고, 이상치는 값과 **사건명**(무단횡단·사고 등)을 같이 적는다.
   평균 금지: 600초 5회에서 [1.40 1.20 1.38 2.41 **10.26**] — 무단횡단 3건이 난 1회가 sd 를 7.6배로 부풀렸다.
   이상치 제외 sd 0.549 vs 300초 0.515 = 사실상 동일.
   **`corner_frac` 을 같이 적는다** — 코너가 거의 없는 주행인지 보이게.
4. **지속시간은 300초 유지, 조건당 n=3.** 600초는 sc·amp 분산을 줄이지만 **평균이 전부 이동**해
   (sc 10.04→5.43, amp .150→.108, prog 14.2→27.4) 기존 300초 수치와 비교 불가가 된다.
   300초 n=3 의 amp MDE 26% 면 우리가 쫓는 평활 효과를 판정하기 충분하다.
   600초는 **300초에서 합격한 후보의 최종 확인용**으로만 쓰고, 그때는 기준선도 600초로 다시 잰다.
