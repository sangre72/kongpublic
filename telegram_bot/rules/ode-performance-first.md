# 속도 품질 최상·군더더기 없는 코드 (MUST — u_5545, 2026-09-22)

> 오너: "모든 요소요소에 속도적인 퀄리티는 최상이어야 해. 군더더기 없는 소스코드. 효율이 없는 부분은 계산하는 게 맞아. 루틴들 확인은 그때그때 충실하게."

## 규칙
1. **경로마다 시간을 잰다.** 캡처→전처리→추론→명령 각 단계 ms 를 실측해 남긴다(gpu_drive 의 lat/inf, 패널 Latency 줄). 추정 금지.
2. **비효율은 계산으로 증명하고 없앤다.** 예: JPEG/HTTP 13fps(23~66ms) → SCK/CoreML 6ms(2026-09-22). 복사(concatenate 이중 메모리), 불필요한 인코딩, 폴링 대기 같은 것은 수치로 잡아 제거.
3. **군더더기 금지.** 죽은 코드·중복 경로·쓰지 않는 분기는 같은 커밋에서 지운다. 새 경로가 검증되면 옛 경로는 기본값에서 뺀다(폴백으로만).
4. **루틴 점검은 그때그때.** 새 루틴을 넣으면 즉시 실측(프레임률·지연·메모리)하고 회귀 케이스로 돌린다. 나중에 몰아서 하지 않는다.

## 현재 기준선(2026-09-22)
캡처 32~38fps(페이지 그리기 한계, GPU 비우면 50~60 목표) · 화면→명령 6ms · 추론 1~2ms · 판정기(규칙) 60fps.
