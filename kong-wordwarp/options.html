API 가입 가이드

Claude API 가입 및 키 발급 방법

  1. Anthropic 웹사이트(https://www.anthropic.com/api)에 접속합니다.
  2. 오른쪽 상단의 "Sign up" 버튼을 클릭합니다.
  3. 이메일과 비밀번호를 입력하여 계정을 생성합니다.
  4. 로그인 후 "API Keys" 탭으로 이동합니다.
  5. "Create API Key" 버튼을 클릭합니다.
  6. 키 이름을 입력하고 생성합니다.
  7. 발급받은 API 키를 복사하여 위의 Claude API 키 입력란에 붙여넣습니다.

※ Claude API는 신용카드 등록이 필요하며, 사용량에 따라 요금이 청구됩니다.
※ API 키는 sk-ant-api03-... 형식으로 시작합니다.

ChatGPT API 가입 및 키 발급 방법

  1. OpenAI 웹사이트(https://platform.openai.com/signup)에 접속합니다.
  2. "Sign up" 버튼을 클릭하여 계정을 생성합니다.
  3. 이메일 인증을 완료합니다.
  4. 로그인 후 오른쪽 상단의 프로필 아이콘 우측의 Dashboard 클릭하고 좌측 메뉴의 "API keys"를 선택합니다.
  5. "Create new secret key" 버튼을 클릭합니다.
  6. 키 이름을 입력하고 생성합니다.
  7. 발급받은 API 키를 복사하여 위의 ChatGPT API 키 입력란에 붙여넣습니다.

※ OpenAI API는 신용카드 등록이 필요하며, 사용량에 따라 요금이 청구됩니다.
※ API 키는 sk-... 형식으로 시작합니다.

Grok API 가입 및 키 발급 방법

  1. X.AI 웹사이트(https://x.ai)에 접속합니다.
  2. 계정으로 로그인합니다.
  3. 상단 API 메뉴를 클릭합니다.
  4. "Start building now" 버튼을 클릭합니다.
  5. 좌측에 API Keys 메뉴를 클릭합니다.
  6. API 키를 발급받습니다.
  7. 발급받은 API 키를 복사하여 위의 Grok API 키 입력란에 붙여넣습니다.

※ API 키는 xai-... 형식으로 시작합니다.

DeepL API 가입 및 키 발급 방법

  1. DeepL API 웹사이트(https://www.deepl.com/pro-api)에 접속합니다.
  2. "Sign up for free" 버튼을 클릭합니다.
  3. 이메일 주소와 비밀번호를 입력하여 계정을 생성합니다.
  4. 계정 활성화를 위해 이메일 인증을 완료합니다.
  5. 로그인 후 https://www.deepl.com/ko/your-account/subscription 계정 페이지로 이동합니다.
  6. API keys 메뉴로 이동합니다(https://www.deepl.com/ko/your-account/keys)
  7. 무료 버전의 API 키는 위의 DeepL API Key (무료) 입력란에 붙여넣습니다.
  8. 유료 버전의 API 키는 위의 DeepL API Key (유료) 입력란에 붙여넣습니다.

※ DeepL API 무료 버전은 월 50만 자까지 번역 가능합니다.
※ 유료 버전으로 업그레이드하면 더 많은 텍스트를 번역할 수 있습니다.
※ 저는 유료 버전으로 업그레이드하면 무료 버전의 API 는 사용 할 수 없었습니다. 참고하세요.

DeepL API 사용 시 주의사항

무료 API 키 https://api-free.deepl.com 엔드포인트를 사용해야 합니다.
유료 API 키 https://api.deepl.com 엔드포인트를 사용해야 합니다.

무료 API 키를 사용하면서 "Wrong endpoint. Use https://api.deepl.com" 오류가 발생한다면:

1. DeepL API (무료) 옵션을 선택했는지 확인하세요.
2. 실제로 무료 API 키를 사용하고 있는지 확인하세요.

마우스 우클릭을 누른 상태에서 휠을 위/아래로 움직여 기능을 활성화/비활성화할 수 있습니다.

디버그 모드를 활성화하면 오류 메시지 및 API 통신 정보가 브라우저 콘솔에 표시됩니다.
