# Real-time Translator with Claude

브라우저에서 선택한 텍스트를 실시간으로 번역해주는 확장 프로그램입니다.

## 기능

- 텍스트 선택 후 번역 메뉴를 통한 실시간 번역
- 다양한 번역 서비스 지원 (Claude API, ChatGPT API, Grok API, DeepL API)
- 텍스트 요약 기능
- 인라인 번역 기능 (웹페이지 내에 번역 결과 표시)
- 자막 실시간 번역 기능
- 다국어 인터페이스 지원 (한국어, 영어, 독일어, 일본어, 중국어)
- 선호하는 언어 설정 기능

## 설치 방법

1. 이 저장소를 다운로드하거나 클론합니다.
2. Chrome 브라우저에서 `chrome://extensions/` 페이지로 이동합니다.
3. 우측 상단의 '개발자 모드'를 활성화합니다.
4. '압축해제된 확장 프로그램을 로드합니다' 버튼을 클릭합니다.
5. 다운로드한 확장 프로그램 폴더를 선택합니다.

## 설정 방법

1. 확장 프로그램 아이콘을 클릭하거나 확장 프로그램 관리 페이지에서 '옵션'을 클릭하여 설정 페이지로 이동합니다.
2. 사용할 번역 서비스를 선택합니다:
   - Claude API
   - ChatGPT API
   - Grok API
   - DeepL API (무료)
   - DeepL API (유료)
3. 선택한 서비스에 맞는 API 키를 입력합니다.
4. 인터페이스 언어를 선택합니다 (한국어, 영어, 독일어, 일본어, 중국어).
5. 선호하는 언어를 선택합니다 (번역 메뉴에 표시될 언어).
6. '저장' 버튼을 클릭하여 설정을 저장합니다.

## API 키 획득 방법

### Claude API
1. [Anthropic 웹사이트](https://www.anthropic.com/)에서 계정을 생성합니다.
2. Claude API 콘솔에서 API 키를 생성합니다.

### ChatGPT API
1. [OpenAI 웹사이트](https://openai.com/)에서 계정을 생성합니다.
2. API 키 섹션에서 새 API 키를 생성합니다.

### Grok API
1. [X.AI 웹사이트](https://x.ai/)에서 계정을 생성합니다.
2. API 키를 생성합니다.

### DeepL API
1. [DeepL API 웹사이트](https://www.deepl.com/pro-api)에서 계정을 생성합니다.
2. 무료 또는 유료 API 플랜을 선택합니다.
3. API 키를 생성합니다.

## 사용 방법

### 기본 번역
1. 웹페이지에서 번역하고 싶은 텍스트를 선택합니다.
2. 마우스 오른쪽 버튼을 클릭하면 번역 메뉴가 나타납니다.
3. 원하는 언어를 선택하여 번역합니다.

### 인라인 번역
1. 웹페이지에서 번역하고 싶은 텍스트를 선택합니다.
2. 번역 메뉴에서 '인라인 번역'을 선택합니다.
3. 선택한 텍스트 바로 아래에 번역 결과가 표시됩니다.

### 텍스트 요약
1. 웹페이지에서 요약하고 싶은 텍스트를 선택합니다.
2. 번역 메뉴에서 '요약하기'를 선택합니다.
3. 선택한 텍스트의 요약 결과가 팝업으로 표시됩니다.

### 자막 실시간 번역
1. 비디오 플레이어가 있는 웹페이지에서 텍스트를 선택합니다.
2. 번역 메뉴에서 '자막 실시간 번역'을 선택합니다.
3. 비디오의 자막이 실시간으로 번역되어 표시됩니다.
4. 단축키 Alt+S 또는 Option+S를 사용하여 자막 번역을 켜고 끌 수 있습니다.

## 단축키

- **Ctrl+Shift+X**: 번역 기능 켜기/끄기
- **Alt+S / Option+S**: 자막 실시간 번역 켜기/끄기
- **ESC**: 번역 또는 요약 작업 취소
- **마우스 가운데 버튼**: 번역 기능 켜기/끄기

## 디버그 모드

설정 페이지에서 '디버그 모드 활성화' 옵션을 체크하면 브라우저 콘솔에 오류 메시지 및 API 통신 정보가 표시됩니다.

## DeepL API 사용 시 주의사항

- **무료 API 키**는 `https://api-free.deepl.com` 엔드포인트를 사용해야 합니다.
- **유료 API 키**는 `https://api.deepl.com` 엔드포인트를 사용해야 합니다.

무료 API 키를 사용하면서 "Wrong endpoint. Use https://api.deepl.com" 오류가 발생한다면:
1. **DeepL API (무료)** 옵션을 선택했는지 확인하세요.
2. 실제로 무료 API 키를 사용하고 있는지 확인하세요.
