RECIPE: krea2_gguf_t2i (Krea2 Turbo GGUF text-to-image via direct API submit — ★성공확정)
REG: http://127.0.0.1:8188 (ComfyUI 웹UI/API), macOS MPS
WHY: overnight-video-learning(2026-08-26) 세션 3번째 모델 브랜치. Wan2.2(I2V)/LTX-2.3(skip, 모델없음) 다음 순서. Krea2=이미지 전용(비디오 아님, u_2419에서 재검증 확정).

★★★핵심: 캔버스 UI 조립 없이 API `/prompt` 직접 제출로 완전 성공 — STRATEGY_canvas_learning.txt 원칙("사전제작 JSON+로드가 항상 우선") 최고 실증 사례.

STEPS:
1. 노드 설치: `git clone https://github.com/RealRebelAI/ComfyUI-GGUF_KREA-2.git` → `custom_nodes/`(기존 city96/ComfyUI-GGUF와 별개 fork, krea2 아키텍처 지원 위해 필수).
2. 모델 3종 다운로드(network-budget 고려, Turbo Q3_K_M 최소사양 선택):
   - GGUF: `models/diffusion_models/Krea2/Krea-2-Turbo-Q3_K_M.gguf`(6GB, Abiray/Krea-2-Turbo-GGUF repo)
   - text_encoder: `models/text_encoders/qwen3vl_4b_fp8_scaled.safetensors`(5.2GB, Comfy-Org/Qwen3-VL repo)
   - VAE: `models/vae/qwen_image_vae.safetensors`(254MB, Comfy-Org/Krea-2 repo)
3. API 포맷 prompt JSON 직접 작성(파이썬 dict, 캔버스 조립 불필요):
   - `UnetLoaderGGUF`(unet_name="Krea2/Krea-2-Turbo-Q3_K_M.gguf")
   - `CLIPLoader`(clip_name="qwen3vl_4b_fp8_scaled.safetensors", **type="krea2"**★필수 — 일반 type이면 실패, nodes.py CLIPLoader INPUT_TYPES의 콤보목록에 krea2 존재 확인함)
   - `VAELoader`(vae_name="qwen_image_vae.safetensors")
   - `CLIPTextEncode` x2(positive/negative)
   - `EmptyLatentImage`(832x1216 등 원하는 해상도)
   - `KSampler`(steps=8, cfg=1.0, sampler=euler, scheduler=simple — Turbo 증류모델은 8스텝+CFG1.0이 표준)
   - `VAEDecode` → `SaveImage`
4. 제출: `{"prompt": {...}}` 형태로 wrap 후 `curl -X POST http://127.0.0.1:8188/prompt -H "Content-Type: application/json" -d @payload.json`
5. 결과: `prompt_id`+`node_errors:{}`(빈 객체=성공) 반환 확인 → `curl queue`로 running 확인 → 완료 후 output/*.png 확인.

VERIFY:
- API 응답 `node_errors`가 빈 딕셔너리인지 확인(비어있지 않으면 노드/파라미터 오류).
- 완료 로그: `Prompt executed in NN.NN seconds`(Turbo는 130~140초 수준, MPS 기준 — GGUF I2V 30분대에 비해 훨씬 빠름, 이미지 전용+8스텝 증류모델 특성).
- 이미지 크기 python PIL로 실측(요청 width/height와 일치 확인).
- 실측 시각확인(Read 도구로 이미지 직접 확인) — 특히 인물류 프롬프트는 얼굴 왜곡/블러 여부 육안 필수 확인.

★안전 관련 교훈(2026-08-26 a_2414/2417/2421 체인): 캐릭터 레퍼런스 사용시 원작(캐논) 의상 디자인을 WebSearch로 먼저 확인하고 그걸 프롬프트에 명시할 것 — 팬아트 이미지 레퍼런스(특히 다키마쿠라/화보 스타일)는 노출도가 원작과 크게 다를 수 있어 그대로 쓰면 부적절한 결과 위험. Negative 프롬프트에 "nsfw, nude, revealing clothing" 명시하는 것도 안전판으로 유효.

LIMIT/OPEN:
- 이번 프롬프트는 텍스트만으로 캐릭터 특징(검은 머리+노란눈) 재현 — 이미지 레퍼런스(IPAdapter 등)로 특정 캐릭터를 더 정확히 재현하려면 별도 조사 필요(시도 안 함, 텍스트만으로 충분한 결과 얻음).
