RECIPE: timeline_edit_split_delete
REG: a_904/ar_904(2026-08-19)
WHY: 임포트한 미디어를 타임라인에 배치→자르기(split)→불필요 구간 삭제, 기본 편집 흐름.
STEPS:
1. Media 패널의 클립 썸네일을 타임라인 트랙 영역으로 press-drag-release(kongtrol input drag --scale 1.0)로 드래그 → 트랙에 클립 배치됨(클립 라벨+길이 표시).
2. 재생헤드 이동: 타임라인 상단 눈금자(ruler, 트랙 바로 위 시간표시줄) 원하는 시간 지점 클릭 → 흰 세로선(playhead)이 그 지점으로 이동(우측하단 타임코드로 확인).
3. 자르기: 툴바의 Split 아이콘(가위 모양, ⌘+B 동일) 클릭 → 재생헤드 위치에서 클립이 2개로 분리.
4. 삭제: 분리된 클립 중 지울 쪽 클릭해 선택(흰 테두리로 표시) → 툴바의 휴지통 아이콘 클릭 → 클립 제거, 타임라인 총 길이 갱신.
VERIFY: split 직후 클립 2개(각각 라벨+길이 표시), delete 후 1개로 복귀+길이가 자른 지점까지로 축소.
NOTE: 삭제는 Delete/Backspace 키가 kongtrol key 목록에 없어 미지원 — 반드시 툴바 휴지통 아이콘 클릭으로 수행. 좌표는 세션별 재계산 필요.
