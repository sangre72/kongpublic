===== 📋 STEP-BY-STEP DELETE PROCEDURE =====

**[1] YouTube Studio 콘텐츠 리스트 진입**

Chrome 포커싱:
$ open -a "Google Chrome"
(YouTube Studio 이미 열려있으면 포커스만)

(2초)

페이지 새로고침:
$ kongtrol input chord cmd r --yes

(5~6초 대기 — 콘텐츠 목록 로드)

**[2] 삭제 대상 동영상 찾기**

a11y로 콘텐츠 목록에서 특정 동영상 찾기:
$ kongtrol see --a11y | grep -i "[동영상_키워드]" -B2 -A2

예시 (scene_07 말띠):
$ kongtrol see --a11y | grep -i "말띠\|협력" -B2 -A2

출력 예시:
```
AXRow "2026년 8월 21일 말띠 🐴 협력이 당신을 이끌어줄 날 (youtube.com/shorts/XXXXX)" @(200,450)
  ├─ AXCheckbox @(210,450)
  └─ AXButton "추가 작업" @(1800,450)
```

**[3] 항목 선택 (체크박스 또는 3점 메뉴)**

**방법 A: 체크박스 선택** (권장):
$ kongtrol input click [체크박스_X] [체크박스_Y] --yes

(1초 — 행 선택됨)

또는

**방법 B: 추가 작업 메뉴 직접 클릭**:
$ kongtrol input click [추가작업_X] [추가작업_Y] --yes

(1초 — 3점 메뉴 또는 액션 메뉴 열림)

**[4] 추가 작업 메뉴 찾기 및 클릭**

만약 체크박스로 선택했다면, 위의 "추가 작업" 버튼이나 메뉴 아이콘 찾기:
$ kongtrol see --a11y | grep -i "추가작업\|more\|메뉴\|⋮" -B1 -A1

메뉴 버튼 좌표 추출:
$ kongtrol input click [메뉴_X] [메뉴_Y] --yes

(1초 — 메뉴 팝업 열림)

**[5] 메뉴에서 "삭제" 옵션 찾기**

$ kongtrol see --a11y | grep -i "삭제\|delete\|제거" -B1 -A1

출력 예시:
```
AXMenuItem "완전삭제" @(1750,520)
```

또는:
```
AXMenuItem "이 동영상 삭제" @(1750,520)
```

**[6] 완전삭제 클릭**

$ kongtrol input click [삭제_X] [삭제_Y] --yes

(2초 — 확인 다이얼로그 열림)

**[7] 확인 다이얼로그 처리**

확인 다이얼로그 상태 확인:
$ kongtrol see --a11y | grep -i "확인\|이해합니다\|삭제됨\|정말\|삭제하겠습니다" -B2 -A2

출력 예시:
```
AXDialog "동영상 삭제"
  ├─ AXStaticText "이 동영상을 삭제하시겠습니까? 이 작업은 되돌릴 수 없습니다."
  ├─ AXButton "이해합니다" @(754,753)
  └─ AXButton "완전삭제" @(1226,819)
```

★확인 버튼 클릭 (2가지 방식):

**선택지 1: "이해합니다" 버튼** (확인용):
$ kongtrol input click 754 753 --yes

(1초)

$ kongtrol see --a11y | grep -i "삭제 버튼\|완전삭제" -B1 -A1
(최종 삭제 버튼 확인)

**선택지 2: "완전삭제" 버튼** (최종 삭제):
$ kongtrol input click 1226 819 --yes

(2초)

**[8] 삭제 완료 확인**

다이얼로그가 닫혔는지 확인:

콘텐츠 목록에서 삭제된 항목이 사라졌는지 확인:
$ kongtrol see --a11y | grep -i "[동영상_키워드]"
