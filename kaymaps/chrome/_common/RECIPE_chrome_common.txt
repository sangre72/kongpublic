STEPS(모든 kongtrol input 호출에 --yes 필수):

2. 주소창 이동/새탭:
   - 새 탭: `input chord cmd t --yes` → 자동 포커스된 주소창에 `input text "<url>" --yes` → `input key return --yes`.
   - ★함정: 페이지 로드 전에 텍스트 입력하면 포커스가 페이지 내 필드로 새는 경우 있음(로그인폼 오타 유입 등) — 주소 입력 전 새 탭 생성 직후(주소창 자동포커스 상태)에 바로 입력할 것, 로드 완료까지 기다리지 말 것(주소창은 즉시 포커스됨).
   - a11y 참고좌표(예시 세션, 창 크기 따라 달라짐): AXTextField "주소창 및 검색창" ~(920,102).

3. 탭 전환/닫기:
   - 새 탭 버튼: AXButton "새 탭" (예: 616,60).
   - 탭 검색: AXPopUpButton "탭 검색" (예: 106,59).
   - 개별 탭 닫기: 탭 우측 X 아이콘(a11y 재조회 권장, 탭 개수따라 좌표 이동).

4. 네비게이션: AXButton "뒤로"/"앞으로"/"새로고침" — 브라우저 툴바 좌측 고정(예: 20,102 / 59,102 / 95,102).

   - "보기" 메뉴 → "개발자 정보"(AXMenuItem, 서브메뉴 트리거) 클릭 → 서브메뉴 → "개발자 도구"(AXMenuItem) 클릭.
   - 서브메뉴는 클릭형(hover 아님) — 상위 메뉴아이템 클릭 시 서브메뉴 a11y 노출, 그 안의 "개발자 도구" 클릭.

6. DevTools 패널 구조(우측 도킹 기준, 열린 후 a11y 재조회 권장 — 콘텐츠에 따라 좌표 이동):
