===== 개념 (혼동주의) =====
- CHROME BROWSER PROFILE ≠ GOOGLE WEB SESSION.
  * Chrome profile = 브라우저 사용자(북마크/확장/저장비번). 우상단 프로필칩(브라우저 크롬UI).
  * Google web session = accounts.google.com 쿠키에 로그인된 Google 계정(들). 웹페이지 우상단 아바타.
  * 하나의 Chrome profile 안에서 여러 Google 계정 multi-login 가능(owner + kongbot757 동시).
- MULTI-LOGIN + /u/ 인덱스: 여러 계정 로그인시 각 계정은 URL의 /u/N 으로 접근.
  * gmail.com/mail/u/0/ = 첫번째(대개 owner), /u/1/ = 두번째 추가계정, ...
  * ★/u/<email>/ 형식은 무효(Temporary Error) — 반드시 /u/<숫자>/. 어느 숫자가 누구인지는 아바타 메뉴에서 확인.
  * 서비스(예 Discord 웹)가 "Google로 로그인"할 때 어느 계정 쓸지는 계정선택창에서 고름(multi-login이면 chooser 뜸).

===== 아바타 칩 계정-chooser (웹페이지 우상단) =====
- 클릭 대상 = a11y "Google 계정: <이름> (<email>)" 아바타(예 @1466,315).
- 메뉴 항목: (a) "다른 계정 추가"=새 계정 로그인(owner 유지, 세션에 추가) (b) 계정 리스트 클릭=그 계정으로 전환 (c) "모든 계정에서 로그아웃"=전체 로그아웃(주의, owner도 나감→금지).
- ★owner 로그아웃 금지. 항상 "다른 계정 추가"로 kongbot757 ADD(전환은 /u/ 인덱스나 chooser로).

===== 로그인 폼 필드 프로토콜 (MUST, 재사용 field-focus rule) =====
- 이메일 단계: "이메일 또는 휴대전화" 필드 focus 확인 → kongbot757@gmail.com 타이핑 → 평문 이메일 보이는지 검증 → 다음.
- 비밀번호 단계: "비밀번호" 필드 focus 확인 → 타이핑 → 마스킹 dots 검증. ★타이핑前 a11y로 focused 필드 label 읽어 일치확인(비번을 이메일칸에 넣는 사고 방지).
- Google 계정 비밀번호 ≠ Discord 비밀번호(별개). Gmail 로그인엔 Google 비번 필요 — 없으면 유저에 pause.
